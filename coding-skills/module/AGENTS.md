# Coding Skills

This module provides methodology and style skills for writing better code.

## Available Skills

- **as-karpathy** -- Apply Andrej Karpathy's LLM coding guidelines: think before coding, simplicity first, surgical changes, goal-driven execution
- **code-simplifier** -- Simplify and refine code for clarity, consistency, and maintainability while preserving all functionality

## Available Commands

- `/as-karpathy` -- Apply Karpathy's guidelines to a task
- `/code-simplifier` -- Simplify and refine code
