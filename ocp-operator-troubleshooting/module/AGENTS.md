# OpenShift Operator Troubleshooting

This module provides skills for troubleshooting OLM-managed operators on OpenShift.

## Prerequisites

- `oc` (OpenShift CLI) for live cluster analysis, and/or `omc` for must-gather analysis
- OpenShift 4.12+ cluster

## Available Skills

- **ocp-operator-troubleshoot** -- Three-phase operator diagnostic: OLM triage, workload triage, and deep source code analysis. Supports both live cluster (`oc`) and must-gather (`omc`) modes.
